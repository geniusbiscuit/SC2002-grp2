# Test notes

## How to run

```
mvn test                                     # unit tests (needs internet the first time for JUnit)
scripts/replay.sh scripts/stage1-victory.txt # replay a recorded run
scripts/replay.sh scripts/stage1-defeat.txt
```

Each line in a script is what a player would type. The game echoes it, so the output reads like a real
session. Saved transcripts are in `docs/runs/`.

## Recorded runs

| Run | Result |
|---|---|
| Victory | 5 paid, $66.00, average satisfaction 79.2, nobody left |
| Defeat | Only "Wait": 0 paid, $0.00, 2 customers left |

The victory script was generated by `GreedyManager` (in `src/test/.../support`): the Waiter serves if
possible, otherwise takes an order, otherwise seats the least satisfied customer, and the Chef works on the
order closest to done.

## Unit tests

| Test class | What it checks |
|---|---|
| `TurnRulesTest` | The brief's worked example turn by turn, staff order, one action per staff per turn, serving only on a later turn, rejected choices, abandonment, win targets, 18 turns, max five payments |
| `EntityRulesTest` | Food rule, Cashier order and timing, table freed after payment, satisfaction never below 0 |
| `ScriptedRunTest` | Both scripts through the real UI, bad input asked again |
| `MoneyTest` | Cents formatting and rounding |
